# Automated Structure Extraction from FDA 510(k) Clearance Summaries

This project explores the automated extraction of structured information from FDA 510(k) medical device clearance summaries using **Large Language Models (LLMs)**.

### What the project includes

* Processing of FDA 510(k) clearance summaries from **2015–2024**
* LLM-based extraction into a structured **JSON schema**
* Manual gold-standard annotation for evaluation
* Accuracy and completeness analysis
* Random spot-check validation
* PCA and visualization of extracted data

### Dataset

The working dataset contains **1,221 deduplicated 510(k) records**.

### Technologies

**Python · LLMs · JSON · PCA · Data Analysis & Visualization**

### Repository

The repository contains selected source code, analysis results, visualizations, and representative JSON outputs from the project.
